## 🎯 Features

### Free Tier
- 1 household
- Up to 2 members
- Unlimited shifts & notes
- Shift patterns
- Two-week calendar view

### Standard Tier (£2.99/month)
- 1 household
- Up to 4 members
- All Free features
- Ad-free for admin

### Premium Tier (£7.99/month)
- Unlimited households
- Up to 12 members per household
- Completely ad-free for everyone
- Priority support
